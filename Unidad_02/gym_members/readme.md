Acerca del conjunto de datos

Este conjunto de datos ofrece una visión detallada de las rutinas de ejercicio, los atributos físicos y las métricas de aptitud física de los socios del gimnasio. Contiene 973 muestras de datos, incluyendo indicadores clave de rendimiento como la frecuencia cardíaca, las calorías quemadas y la duración del entrenamiento.

Cada registro también incluye datos demográficos y niveles de experiencia, lo que permite realizar un análisis de los patrones de aptitud física, la progresión de los atletas y las tendencias relacionadas con la salud.
| Variable                                      | Descripción                                                                               |
| --------------------------------------------- | ----------------------------------------------------------------------------------------- |
| **Edad**                                      | Edad del socio del gimnasio.                                                              |
| **Género**                                    | Género del socio del gimnasio (Masculino o Femenino).                                     |
| **Peso (kg)**                                 | Peso del miembro expresado en kilogramos.                                                 |
| **Altura (m)**                                | Altura del miembro expresada en metros.                                                   |
| **Max_BPM**                                   | Frecuencia cardíaca máxima, en latidos por minuto, durante las sesiones de entrenamiento. |
| **Avg_BPM**                                   | Frecuencia cardíaca promedio durante las sesiones de entrenamiento.                       |
| **Frecuencia cardíaca en reposo**             | Frecuencia cardíaca del miembro antes de comenzar el entrenamiento.                       |
| **Duración de la sesión (horas)**             | Tiempo que dura cada sesión de entrenamiento, expresado en horas.                         |
| **Calorías_Quemadas**                         | Total de calorías quemadas durante cada sesión de entrenamiento.                          |
| **Workout_Type**                              | Tipo de entrenamiento realizado, como Cardio, Fuerza, Yoga o HIIT.                        |
| **Porcentaje de grasa**                       | Porcentaje de grasa corporal del miembro.                                                 |
| **Ingesta de agua (litros)**                  | Cantidad de agua ingerida diariamente durante los entrenamientos.                         |
| **Frecuencia de entrenamiento (días/semana)** | Número de días que el miembro realiza ejercicio por semana.                               |
| **Nivel de experiencia**                      | Nivel de experiencia del miembro: principiante (1), intermedio (2) o experto (3).         |
| **IMC**                                       | Índice de Masa Corporal, calculado a partir del peso y la altura.                         |
