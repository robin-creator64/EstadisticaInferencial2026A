
## Acerca del conjunto de datos

### Descripción

Este conjunto de datos proporciona una visión general de los diferentes factores que influyen en el rendimiento académico de los estudiantes en los exámenes. Incluye información sobre los hábitos de estudio, la asistencia a clases, la participación de los padres y otros aspectos que pueden influir en el éxito académico.

### Descripción de las columnas

| **Atributo** | **Descripción** |
| :--- | :--- |
| **Horas_Estudiadas** (`Hours_Studied`) | Número de horas dedicadas al estudio por semana. |
| **Asistencia** (`Attendance`) | Porcentaje de clases a las que asiste el estudiante. |
| **Participación_Paterna** (`Parental_Involvement`) | Nivel de participación de los padres en la educación del estudiante (Bajo, Medio, Alto). |
| **Acceso_a_Recursos** (`Access_to_Resources`) | Disponibilidad de recursos educativos (Bajo, Medio, Alto). |
| **Actividades_Extracurriculares** (`Extracurricular_Activities`) | Indica si el estudiante participa en actividades extracurriculares (Sí, No). |
| **Horas_de_Sueño** (`Sleep_Hours`) | Promedio de horas de sueño por noche. |
| **Calificaciones_Anteriores** (`Previous_Scores`) | Calificaciones obtenidas en exámenes anteriores. |
| **Nivel_de_Motivación** (`Motivation_Level`) | Nivel de motivación del estudiante (Bajo, Medio, Alto). |
| **Acceso_a_Internet** (`Internet_Access`) | Indica si el estudiante tiene acceso a internet (Sí, No). |
| **Sesiones_de_Asesoría** (`Tutoring_Sessions`) | Número de sesiones de asesoría académica recibidas por mes. |
| **Ingresos_Familiares** (`Family_Income`) | Nivel de ingresos de la familia (Bajo, Medio, Alto). |
| **Calidad_Docente** (`Teacher_Quality`) | Calidad de los profesores (Baja, Media, Alta). |
| **Tipo_de_Escuela** (`School_Type`) | Tipo de escuela a la que asiste el estudiante (Pública, Privada). |
| **Influencia_de_Compañeros** (`Peer_Influence`) | Influencia de los compañeros en el rendimiento académico (Positiva, Neutral, Negativa). |
| **Actividad_Física** (`Physical_Activity`) | Promedio de horas de actividad física por semana. |
| **Dificultades_de_Aprendizaje** (`Learning_Disabilities`) | Indica si el estudiante presenta dificultades de aprendizaje (Sí, No). |
| **Nivel_Educativo_de_los_Padres** (`Parental_Education_Level`) | Nivel educativo más alto alcanzado por los padres (Preparatoria, Universidad, Posgrado). |
| **Distancia_del_Hogar** (`Distance_from_Home`) | Distancia entre el hogar y la escuela (Cerca, Moderada, Lejos). |
| **Género** (`Gender`) | Género del estudiante (Masculino, Femenino). |
| **Calificación_del_Examen** (`Exam_Score`) | Calificación final obtenida en el examen. |
